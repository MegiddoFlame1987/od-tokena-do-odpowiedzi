A bit is one switch

Like a light switch. On is 1, and off is 0.

A processor has billions of these tiny switches. They are called transistors.

Level 2 · Writing numbers

The place sets the value

Each place has a fixed value. You add up the values where there is a 1.

Think of the number 111: the same digits mean 100, 10 and 1, because they stand in different places. In bits, each place is 2 times bigger than the one before.

Level 3 · Logic gates

Switches turn into logic

A gate is a simple rule. It takes bits in and gives one bit out.

A gate understands nothing. Current either flows or it does not. There are 4 basic rules.

GateGives 1 when
NOT
not		The input is 0. Like a lamp with a dusk sensor: it shines when there is no sun.
AND
and		Both inputs are 1. Like two switches one after the other.
OR
or		At least one input is 1. Like two switches side by side.
XOR
exclusive OR		The inputs are different, "either one or the other". Like a two-way switch on a staircase.

Level 4 · Adder

Gates add numbers

Adding two bits has only 4 cases. Two gates cover all of them.

You add longer numbers column by column, from the right, like on paper. When a column comes to 10, you write 0 and carry 1 to the next column.

U4B · Adding 4 bits

Task

4 bits hold numbers up to 15. Set A and B so that the true result goes above 15.

RememberXOR gives the digit, and AND gives the carry. When the last carry has nowhere to go, it falls off and the result wraps round.

More: what this looks like in a chip

A column has 3 bits: A, B and the carry. A circuit of 5 gates (2 XOR, 2 AND and an OR) works out the sum and the new carry from them. This is a full adder. A processor has a row of them side by side, one for each bit.

When the carry falls off, the processor sets an overflow flag. The program decides what to do about it.

Level 5 · Multiplying

Multiplying is shifting and adding

On paper you multiply row by row and add the rows up. In bits it is simpler, because each row is either A or nothing.

You look at the bits of the number B. Where there is a 1, you write A shifted to that place. Shifting 1 place to the left multiplies by 2.

Level 6 · Text

A letter is a number by agreement

Every letter has its own number. The computer stores the number, not the letter.

The numbers are set by a shared agreement. The older one is ASCII (American Standard Code for Information Interchange), and today's is Unicode.

RememberThe same bits are the number 65 one time and the letter A another time. The program gives them their meaning.

Level 7 · Memory

Memory is a row of bytes with no dividers

Memory is a row of numbered lockers. Each one holds 1 byte.

RAM (Random Access Memory, the working memory) has no dividers between pieces of data. The locker number is the address. An instruction says which locker to start reading from and how many to take.

Level 8 · Processor

The processor repeats 3 steps

A processor works like someone reading a recipe. It takes a line, understands it, does it and moves to the next one.

The CPU (Central Processing Unit, the main processor) does nothing more than that. Box A holds the current result, and the counter shows the line number. The program is bits in memory too, so you can change it with a tap.

Level 10 · Memory hierarchy

The processor cannot wait for RAM

The cache is what you hold in your hand. RAM is the desk, and the disk is the cupboard.

The processor calculates faster than RAM can hand it data. So it keeps the data it needs close by. From RAM it takes several neighbouring cells at once, because they will probably be needed soon.

Level 11 · Fractions

Fewer bits means less precision

Like π written as 3.14 instead of 3.1415927. The shorter form is less precise, but it takes less space.

A model's weights are fractions. The fewer bits, the bigger the steps between values.

More: FP16 and BF16 from the AMD slide

FP stands for Floating Point, a number whose decimal point can move. BF stands for Brain Floating Point. The digits in the name are the number of bits. The bits split into 3 parts: the sign says plus or minus, the exponent says how big the number is, and the mantissa says how precisely it is written.

Level 12 · GPU

Thousands of simple units

A CPU is a few master craftsmen. A GPU is thousands of simple helpers who all do the same thing at once.

When peeling a thousand potatoes, the helpers win. On a job where every step depends on the one before, the master wins.

More: names and numbers from the AMD slide

A simple unit is an ALU (Arithmetic Logic Unit, the part that does the sums). One command for many units at once is SIMT (Single Instruction, Multiple Threads: one instruction, many threads).

The slide gives an estimate of 18 to 25 TFLOPS (tera floating-point operations per second, trillions of calculations a second) for the EPYC 9754 CPU and about 1300 TFLOPS for the MI300X.

Level 13 · Language model

An answer is matrix multiplication

A model works like a very strong autocomplete. It works out which token, a small piece of text, fits best next.

Text turns into numbers, the numbers are multiplied by weights, and the result is the chance of each token. This toy model has 15 weights. Large models have billions of them.
