TRAINING MATERIAL · WORKSHOP

From Chat to Workshop

The chat window is only one door to the model. Behind it stands a whole workshop. Skills, which are ready made instructions for the model. The API, which is the entrance for programs. Then gateways to other systems, programs on your computer and GitHub, where all of it is downloaded from. This page shows each of these tools separately. The same question comes up with every one: what can the model touch through it, and who is responsible.

Model names, prices and the list of supported programs: state of play on 8 October 2026. The mechanisms described below age slowly, price lists age fast. Changes go to the News tab.

Part I

Map

You can meet the same model in five places. They differ not in intelligence, but in what the model can touch, who pays and who answers for a mistake.

1 / 16

Five doors to the same model

Pick a door. The model inside does not change. Everything around it does.

Verified: each of the major providers offers the same model at once in chat, in an app, through the API and in developer tools. Simplified: the boundaries are blurring. A desktop app can now start an agent in the terminal, described in part V. Chat in the browser has connectors, which are ready made connections to your email.
2 / 16

What sits where

The most important question with every tool: where does your data physically sit at the moment the model works on it.

ElementUsually runsWhat follows from that
The modelIn the provider cloudEvery piece of text the model reads leaves your computer. The exception: a local model, part V
A tool that reads filesOn your computerOnly what the tool has read reaches the model, not the whole disk
A connector to email or a driveIn the cloud, signed in as youThe model sees what you see. Including what you did not mean to show it
A skillWherever the agent isThe instruction and the scripts run with the permissions of the agent
Verified: models in chat, in an app and through the API run on the servers of the provider, which are its computers in a data centre. What the provider does with the data depends on the plan and the contract, not on the technology. In practice: before the first use at work, check whether the company has a plan under which the provider does not train models on your data.
Part II

Skills

A skill is a folder with an instruction that the model loads by itself when the task fits. That way you do not write the same long instruction for the twentieth time.

3 / 16

A skill is a folder

Inside there is one required file with the instruction. Next to it there can be scripts and reference material. Click a part of the folder to see what it is for.

Verified: the format is an open standard. Anthropic published it in December 2025. Today more than 40 programs read it, among them ChatGPT and Codex, GitHub Copilot, VS Code, Cursor and Gemini CLI. Only two fields are required: the name and the description. Simplified: the example is shortened. A real instruction usually runs from a few dozen to a few hundred lines.
4 / 16

Three levels of loading

You can have a hundred skills and still not clog the context window, which is everything the model sees at one moment. The window is measured in tokens, the pieces of text a model cuts a sentence into. At the start the model sees only the name and the description of each skill. It loads the content only when the task matches the description.

Use of a 200,000 token window
If everything were loaded at once
Verified: the standard describes three levels. The name and the description come to about 100 tokens per skill. The body of the instruction should stay below 5,000 tokens. Scripts are run, and only their result reaches the window. Simplified: the demo assumes every instruction uses the full 5,000 tokens. In practice it is usually less.
5 / 16

Skill, instruction, tool, subagent

Four ways to teach the model something new. They get mixed up, because all of them end as text in the window. What separates them is when and how the text gets there.

WayWhat it isWhen to pick it
An instruction in the conversationText you paste in, or save in the project settingsOne thing that must hold for the whole of this conversation
A skillA folder with an instruction, loaded when the task fitsA repeatable procedure: a report, editing, a quality check
A tool, for example from an MCP server in part IVA function with a description, which the program runs when the model asksThe model has to read or change data in another system
A subagentA separate agent with a clean window, which comes back with a conclusionA broad task that can be split up. Described in part two
In practice: a skill teaches how to do something. A tool gives the ability to do it. A good skill often says which tool to use. Simplified: the names differ between products. In Gemini, skills replace the former "Gems", in ChatGPT a similar role was played by "GPTs".
Part III

API

The API is the way a program talks to a model without a chat window. Behind the same model there is then a different bill: not a subscription, but a charge for every token.

6 / 16

One call, step by step

Everything chat does can be done with a single request from a program. This is what a full exchange looks like: the question, the answer and the bill.

Verified: every API call returns the number of input and output tokens, that is the text sent and the answer. You pay separately for each. Output is always dearer. Simplified: the request has been cut down to the most important fields. Prices from the Anthropic price list, state of play on 8.10.2026.
7 / 16

What it costs

Work it out on your own case. The typical mistake is to count one request instead of a thousand a month.

Verified: list prices in dollars per million tokens from the Anthropic, OpenAI and Google pages, state of play on 8.10.2026. Batch mode, which means processing without waiting for the answer, costs half at all three. Simplified: 700 tokens per page of text is an approximation. The cache discount has been left out, that is the cheaper input when the same text comes back in later requests. It cuts the cost of input by up to 90%. A month is counted as 22 working days.
8 / 16

An API key is the password to your wallet

An API key is a string of characters by which the provider knows who pays. Whoever has your key spends your money. There is no second password here and no code from your phone.

DoDo not
Set a spending limit on your account with the provider before you use the keyDo not paste a key into a chat, an email or a document
A separate key for every project, so that one can be switched offDo not save a key in a file that goes to GitHub
Keep the key in a password manager or in an environment variable, which is a system setting outside the project filesDo not give a company key out for private experiments
After a leak: revoke the key at once, then look for the causeDo not wait with revoking until it has been explained
Verified: all three major providers bill the API up front or against a limit on the account, and let you revoke a key with one click. The Claude Code documentation flatly forbids saving keys in files that go to GitHub. In practice: automated scanners search public projects for keys. Treat a published key as burned.
Part IV

Gateways

Ways for a model to reach other systems, or for one program to reach many models. Every gateway is also a door through which something can come in.

9 / 16

MCP: one plug instead of hundreds of cables

MCP, Model Context Protocol, is a shared standard for connecting models to other systems. Without it, every AI app has to be wired separately to every system. With it, each one connects once. On the system side stands an MCP server: a small program that exposes the tools of that system to the model.

Verified: MCP was created by Anthropic in November 2024. Since December 2025 it has been developed by a foundation under the Linux Foundation, which also includes OpenAI, Google and Microsoft. It is supported by ChatGPT, Gemini CLI, GitHub and Claude. Current version of the specification: 28 July 2026. Simplified: the "multiplication versus addition" sum shows the point of a standard, not the cost of rolling it out. Every MCP server still has to be installed and given permissions.
10 / 16

Local and remote servers

An MCP server can run on your computer or somewhere on the network. That changes who has access to what.

LocalRemote
Where it runsOn your computer, started by the AI appOn a company or provider server, at a network address
Typical exampleFiles in a folder, a local database, the browserEmail, calendar, customer database, GitHub
How you sign inIt runs with your permissions on the computerSign in through the browser, like "Sign in with Google"
Main riskA program from the internet runs on your computerYour data passes through someone else server
Verified: the MCP specification describes exactly these two ways of connecting. Connectors in chat apps are usually remote servers. In practice: in a company the question is not "is MCP safe", but "do I trust this particular server and whoever wrote it".
11 / 16

Model routers

The second family of gateways works the other way round. A model router gives one program, with one key, access to models from many companies. It helps when you want to compare models, or not depend on a single provider.

GatewayWhat it doesWho it is for
OpenRouterOne account and one balance for several hundred models from several dozen providersComparing models, small projects
LiteLLMOpen source software you host yourself. One way of calling more than a hundred providers, with limits and cost accountingA company that wants to keep control in house
Vercel AI GatewayA gateway in the cloud: a request log, budgets, automatic switching to another provider when one is downWeb applications
Cloudflare AI GatewayA middleman for visibility and control: caching of repeated answers, limits, a request logControlling cost and traffic
Verified: feature descriptions from vendor documentation, state of play on 8.10.2026. Unverified: the number of models in OpenRouter comes from the company itself. In practice: a router is one more middleman your data passes through. The same rule as with a remote server.
12 / 16

A gateway works both ways

A tool from an MCP server has a description, which the model reads like any other text. If someone hides an instruction in the tool description, the model may carry it out. This is the same mechanism as prompt injection in part two.

What happenedWhenMechanism
A malicious MCP server hid an instruction in a tool description that told the agent to send WhatsApp chat history to the attackerApril 2025, a researcher demonstrationAn instruction hidden in a tool description
An unofficial MCP server for sending email, downloaded about 1500 times, quietly started adding the address of the attacker to a copy of every message after an updateSeptember 2025A trusted program swapped out in an update
RuleWhy
Servers only from the maker of the system, or from a list approved by ITThe second incident involved an unofficial copy
Human approval before every write and every sendThe MCP specification itself requires this of apps
As many servers as the task needs, no moreEvery server is another set of doors
Verified: both incidents were written up by security researchers. The MCP specification says plainly that a tool can run arbitrary code. Its description must not be trusted up front. Inference: the rules in the second table are a conclusion drawn from the incidents, not a standard.
Part V

Programs

"Exe" is the casual name for a program on your computer, from the ending of program files in Windows. Two completely different things hide under that name. An agent that uses a model in the cloud. And a model that runs entirely on your machine.

13 / 16

An agent in the terminal

The terminal is a window where you type commands as text. A program driven that way is a CLI, from the English command line interface. An agent in the terminal reads and changes files in a folder, runs programs and checks the results. These are the most powerful and the most risky doors from part I.

ProgramCompanyOpen sourceAccess
Claude CodeAnthropicNo. Public on GitHub, but with rights reservedA paid Claude plan or an API key
Codex CLIOpenAIYes, Apache 2.0 licenceA ChatGPT account or an API key
Gemini CLIGoogleYes, Apache 2.0 licenceA free allowance after signing in with a Google account
Copilot CLIGitHubNo. The licence forbids changes to the codeA paid Copilot subscription
Verified: licences, which are the rules for using the code, and the ways of getting access, from the project pages on GitHub and from vendor documentation, state of play on 8.10.2026. All four send the content of the files they read to a model in the cloud. In practice: start an agent in a folder with one project, never in your home folder, where all your files sit. The folder is the boundary of what the agent sees. The permissions from part two apply here literally.
14 / 16

A model on your own computer

Weights are the numbers in which what the model has learned is stored. Models with open weights can be downloaded and run without the internet. Nothing leaves the computer. The price is memory, and the fact that a local model is weaker than the biggest ones in the cloud. Check what your hardware can hold.

Programs for running them: Ollama and LM Studio for an ordinary user, llama.cpp as the engine underneath. Model families available to download: Llama, Qwen, Mistral, Gemma, gpt-oss, DeepSeek.
Verified: Ollama and llama.cpp are open source under the MIT licence, LM Studio has been free for work use as well since July 2025. Quantisation, which means storing the weights with fewer bits, shrinks a model several times over at the cost of accuracy. Simplified: the demo counts about 0.6 GB per billion weights at 4 bits, plus 2 GB of headroom. That is a rule of thumb, not vendor data. Check the file size of the specific model.
Part VI

GitHub

The place most of the tools on this page are downloaded from: skills, MCP servers, programs. And the place where agents increasingly work on their own.

15 / 16

Should you install it: a repository in 60 seconds

A repository, repo for short, is a project folder with the full history of changes. Before you download anything from one, tick off what checks out.

Word on GitHubWhat it means
READMEThe file describing the project, the first thing on the repo page
IssueA bug report or a request for a change
Pull requestA proposed change to the code, waiting for review and approval
ReleaseA tagged version to download
LicenceThe file that says what you may do with the code. No licence means: nothing
Verified: attacks through swapped out packages are real events. In September 2025 a self replicating worm in npm, the registry of ready made code packages, stole developer passwords. GitHub removed more than 500 packages. In March 2026 someone took over the maintainer account of axios, a popular code library. For about 3 hours it shipped a version carrying spyware. Inference: the list in the demo is a first pass filter. Stars and download counts are not proof of safety.
16 / 16

An instruction for the agent in the repo

A repo has a README for people. More and more often it also has a file for agents: how to build the project, how to run the tests, what not to touch. The agent reads it at the start of every job.

File or featureWhat it is
AGENTS.mdPlain text with an instruction for the agent. A shared standard, read by Codex, Copilot, Gemini CLI, Cursor and a dozen or so others. Used in more than 60,000 projects
CLAUDE.mdThe equivalent for Claude Code. When it is missing, Claude Code reads AGENTS.md
Copilot agent in GitHubYou assign an issue to the agent as you would to a colleague. The agent works on its own and hands back a proposed change for review
Claude in GitHub ActionsYou write "@claude" in an issue, the agent analyses the code and proposes a change
Verified: AGENTS.md was handed over together with MCP in December 2025 to a foundation under the Linux Foundation. Both agents in GitHub hand their work back as a proposed change, they do not alter the main version of the code without review. In practice: a file for the agent is the same scratchpad as in part two, only written down for good. This page got one too: two skills in the .claude/skills folder look after editing and the News tab.
